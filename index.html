01 About

This project started as a simple HTML + CSS template and a local Python server. It's now a live, globally distributed static site — every push to main goes straight to production.

  • 0build steps
  • <1sload time
  • 100%static

02 Features

⚡

Instant preview

Edit HTML and CSS, refresh, done. No bundlers, no config, no waiting.

🌍

Global edge

Served from a worldwide CDN so pages load quickly wherever visitors are.

🔒

HTTPS by default

Secure connections out of the box, with certificates handled automatically.

🧪

Safe experiments

Branches get their own preview URLs, so ideas can be tested before they go live.
